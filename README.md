# AL-NOUR Quran Institute Website

A modern, responsive landing page built with **React** and **Tailwind CSS** for the AL-NOUR Quran Institute.  
This project demonstrates clean component architecture, responsive design, and interactive UI elements — ideal for showcasing front‑end development skills.

---

## Features

- **Responsive Design** — optimized for mobile, tablet, and desktop
- **Tailwind CSS Styling** — utility-first approach for fast, consistent UI
- **Reusable Components** — Hero, CTA, About, Courses, Teachers, Pricing, Testimonials, Contact, Footer
- **Interactive Carousel** — Swiper integration for teacher profiles
- **Functional Contact Form** — with validation and success feedback
- **Modern UX** — hover effects, transitions, semantic HTML

---

## Tech Stack

- **React** (functional components, hooks)
- **Tailwind CSS** (responsive utilities, custom styles)
- **Swiper.js** (carousel for teachers section)

---

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/WissemJderi/al-nour
   ```
   
2. Install dependencies:
   ```bash
   npm install
   ```
   
3. Run the development server:
   ```bash
   npm run dev
   ```
